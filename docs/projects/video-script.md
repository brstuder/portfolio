# Modular AI-Leveraged Video Script Library

## Overview

This project consists of a modular file structur and Python script designed to support organizations which want consistent language use, vocabulary, or broader narratives or brand messaging applied to all of their video content in a streamlined, centralized methodology. Video assets including scripts, audio, and image stills, are all compiled into the project structure to support updates as needed to individual elements.

This was not designed to be an entirely automated process. It still requires manual, hands-on involvement depending on the degree of precision or quality that an user requires.

## File Structure

Here is the base file structure of the project:

```
video/
├── canon/                    Durable decisions — read before writing anything
│   ├── voice-and-style.md    Narrator stance, rhythm, structure, banned phrasing, TTS rules
│   ├── audience.md           Who watches, and what they already know
│   ├── visual-theme.md       Image sourcing and visual look
│   ├── glossary.md           One-line canonical definitions, kept consistent across videos
│   └── sourcing-policy.md    Attribution and licensing rules
├── knowledge/                 Research and sources reused across videos
│   ├── sources/
│   └── notes/
├── library/                   One folder per video — the atomic unit of work
│   └── 0001-sample-video/     Video folder structure, uses 4 digit slug identifier for AI tools
│       ├── brief.md           Human-written project outline including title, description, and narrative
│       ├── script.md          Narration script generated via video-script skill
│       ├── assets/
│       │   ├── sourced/       Manually sourced stills, committed to git
│       │   └── prepared/      1920×1080 PNGs — generated by prep.py, gitignored
│       └── audio/             narration.wav + timings.json — generated by prep.py, gitignored
├── series/                    Multi-video arcs (groups videos into a larger narrative)
├── templates/                 Blank starting files
│   └── brief.md               Reusable brief/outline template, copied per new video
├── tools/
│   └── prep.py                Turns a script + sourced images into TTS audio and slide-ready PNGs
├── .claude/
│   ├── agents/
│   └── skills/
│       └── video-script/
│           └── SKILL.md       Defines how the AI drafts/revises script.md from a brief
├── build/                     Scratch space, gitignored
└── CLAUDE.md                  Project conventions the AI follows for every task
```

For my individual purposes, many of these components are superfluous but were designed to support collaboration and consistency across multiple contributors and outputs. Some files, such as `glossary.md` and the `/series` folder, may not be necessary for certain use cases.

### Video-script SKILL.md File

The core functions of this SKILL.md file are:

* Reading the provided video script outline
* Independently fact-checking the outline via popular consensus
* Outputting the video script according to style/language guidelines (established in `/canon`)

After the script has been outputted and then personally approved, a `prep.py` script handles the text-to-speech audio file which reads the video narration. All sourced image files are additionally output as 1920x1080 PNG files.

## Process Breakdown

Here is the total step-by-step process, explaining which parts are leveraged by AI, and which are still manual. I always opted for free or open-source tooling when available, but larger organizations may opt for their in-house enterprise tools based on personal preference. Many of these steps could be further automated, such as staging content for publishing online, but the primary task of this project was to showcase automated script generation and subsequent narration synthesis, which is still largely automatic.

| # | Step | Toolchain | Manual / Automatic | Notes |
|---|------|---------|---------------------|-------|
| 1 | Draft the brief (title, subject, key points, outline) | `templates/brief.md` | Manual | |
| 2 | Draft the narration script from the brief | SKILL.md | Automatic | |
| 3 | Review the script, resolve flagged uncertainties | — | Manual | |
| 4 | Source still images for the narration | — | Manual |  |
| 5 | Synthesize narration audio | `tools/prep.py`, Kokoro TTS, ffmpeg | Automatic | |
| 6 | Fit sourced images to 1920×1080 | `tools/prep.py`, ImageMagick | Automatic | |
| 7 | Assemble narration + images into a video | Kdenlive | Manual | |
| 8 | Publish the finished video, generate closed captions | YouTube | Manual | |

## Key Takeaways

When creating instructional or informative video content, it's a best practice to introduce a system of modularity that allows content to be built, updated, and maintained in one place and at scale. Regardless of how much you lean on AI to automate these processes, all of the tasks can be handled manually and granularly to control video output. Users should mind the excessive token usage involved in script creation; depending on how much independent research the AI must perform and the length of the script output.

Additionally, firsthand video-editing experience is still incredibly valuable and is still necessary to quality content output. As you determine your workflow, this can be automated in tandem with the other project components.
